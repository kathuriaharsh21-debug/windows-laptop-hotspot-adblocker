⚙️ Windows Mobile Hotspot Configuration Checklist
  1. Right-click setup-windows-hotspot.ps1 and select Run with PowerShell as Administrator.
  2. Go to Windows Settings -> Network & internet -> Mobile hotspot -> Turn ON.
  3. In Windows Mobile Hotspot Settings, ensure DNS IP is set to your laptop's Hotspot IP (192.168.137.1).
  4. Connect your Smart TV, laptop, or phone to the Hotspot Wi-Fi network.
